┌──────────────────────────────────────────────────────────────────────────────┐
│  ⚡ INÍCIO RÁPIDO (5 minutos)                                                │
└──────────────────────────────────────────────────────────────────────────────┘

1. Abra o terminal NESTA pasta

2. Execute estes comandos:

   npm install

3. Crie arquivo .env.local com este conteúdo:

   NEXT_PUBLIC_SITE_URL=http://localhost:3000

4. Execute:

   npm run dev

5. Acesse no navegador:

   http://localhost:3000

✅ PRONTO! O site está funcionando!

Para ativar o sistema de doações Stripe:

1. Leia o arquivo: INICIO_RAPIDO.md
   (Tem o guia passo a passo completo)

2. Em resumo:
   - Criar conta no Stripe
   - Copiar chaves da API
   - Adicionar ao .env.local
   - Instalar: npm install stripe
   - Descomentar código nos arquivos de API
   - Reiniciar servidor
