⚡ COMO COMEÇAR:
================================================================================

Opção 1: RÁPIDO (Ver o site funcionando em 2 minutos)
------------------------------------------------------
1. Abra o terminal nesta pasta
2. Execute: npm install
3. Crie arquivo .env.local com: NEXT_PUBLIC_SITE_URL=http://localhost:3000
4. Execute: npm run dev
5. Acesse: http://localhost:3000

Nota: Doações ainda não funcionarão. Siga Opção 2 para habilitar.


Opção 2: COMPLETO (Com sistema de doações Stripe)
--------------------------------------------------
1. Siga os passos da Opção 1
2. Crie conta no Stripe: https://dashboard.stripe.com/register
3. Obtenha as chaves em: Developers → API keys
4. Adicione ao .env.local:
   NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_sua_chave
   STRIPE_SECRET_KEY=sk_test_sua_chave
5. Execute: npm install stripe
6. Descomente o código nos arquivos:
   - app/api/create-checkout-session/route.ts
   - app/api/webhook/route.ts
   (Veja detalhes no arquivo CONFIGURACAO_STRIPE.md)
7. Reinicie: npm run dev
8. Teste com cartão: 4242 4242 4242 4242

🎨 PERSONALIZAR O SITE:
================================================================================

1. LOGO
   - Substitua o ícone <Heart /> nos componentes
   - Adicione sua logo em public/logo.png
   - Atualize os componentes Header.tsx e Hero.tsx

2. CORES
   - Edite: tailwind.config.ts
   - Altere as cores maya-* conforme desejado

3. ANIMAIS
   - Edite: data/animals.ts
   - Adicione/remova/edite animais
   - Use URLs de imagens reais ou locais (public/)

4. CONTATOS
   - Busque por "9999-9999" e substitua pelo seu WhatsApp
   - Busque por "contato@projetomaya.org" e substitua pelo seu email
   - Atualize endereço no Footer.tsx

5. TEXTOS
   - Edite os componentes em components/home/
   - Personalize histórias, missão, valores

🆘 PROBLEMAS COMUNS:
================================================================================

ERRO: "Module not found: stripe"
→ Execute: npm install stripe

ERRO: Variáveis de ambiente não encontradas
→ Crie .env.local e reinicie o servidor

ERRO: Página de doações mostra erro
→ Verifique se descomentou o código das APIs
→ Confirme chaves do Stripe

ERRO: Imagens não aparecem
→ Use URLs válidas em data/animals.ts
→ Ou coloque imagens em public/

ERRO: Webhook não funciona
→ Configure STRIPE_WEBHOOK_SECRET
→ Use stripe listen para desenvolvimento local
→ Configure webhook no dashboard para produção
